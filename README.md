# C# Practice Sandbox 🚀

A dedicated workspace for mastering the fundamentals of C# and the .NET framework. This repository tracks my journey toward becoming a backend developer, focusing on clean code, strong typing, and logical problem-solving.

## 🧠 Learning Roadmap

This repository is divided into specific study modules, each tackling a core concept of software development in C#:

* **Variables & Types:** Exploring primitive data types, memory allocation (float vs. double), and explicit/implicit conversions.
* **Console I/O & Parsing:** Handling user input, standardizing culture settings (`CultureInfo.InvariantCulture`), and safely parsing strings to numeric types.
* **Conditional Logic:** Building decision trees using `if-else` blocks and logical operators (`&&`, `||`).
* **Switch Statements & Expressions:** Managing multiple execution paths using both traditional `switch` statements and modern, concise C# `switch` expressions.

## 💻 Technology Stack

* **Language:** C# 10+
* **Framework:** .NET
* **Environment:** Visual Studio / VS Code / .NET CLI
* **Version Control:** Git & GitHub

## ⚙️ How to Run

1. Clone this repository to your local machine:
   `git clone https://github.com/Felipe-Costaa/csharp-practice-sandbox.git`
2. Navigate into the specific project folder you want to run (e.g., `cd VariablesAndTypes/VariablesAndTypes`).
3. Execute the code using the .NET CLI:
   `dotnet run`
